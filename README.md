# PySpark-ETL-Pipeline

This project implemenets a **production-grade PySpark ETL Pipeline** that processes raw, imperfect e-commerce data (orders, customers, order items, returns) through a complete data engineering workflow: ingestion -> cleaning ->enrichmenr -> aggregation -> analysis -> partitioned output.
